# MAX SHOW TV — دليل العمل الاحترافي

## ماذا تبيع؟

**برنامج مشغّل (Software)** — ليس محتوى ولا اشتراكات Netflix.

| أنت (المزود/البائع) | العميل |
|---------------------|--------|
| MAX SHOW TV + كود تفعيل | يدفع لك اشتراك IPTV |
| رابط M3U من مزود مرخّص | يشاهد القنوات/أفلام/مسلسلات M3U |
| واجهة احترافية | Netflix/شاهد/TOD — اشتراكه الرسمي |

---

## سير العمل اليومي (5 دقائق لكل عميل)

```
1. اشترِ M3U من مزود IPTV مرخّص (قانوني)
        ↓
2. افتح /max-admin → عميل جديد
   • رابط M3U
   • اسم العميل
   • مدة: 30 / 90 / 365 يوم
        ↓
3. انسخ رسالة WhatsApp → أرسل للعميل
        ↓
4. العميل يضغط الرابط → واجهة جاهزة
        ↓
5. عند التجديد: +30 يوم أو +90 يوم من لوحة الإدارة
```

---

## الروابط المهمة

| الرابط | الغرض |
|--------|--------|
| `https://your-domain.com/max-admin` | إدارة الاشتراكات |
| `https://player.your-domain.com/?code=123456` | رابط العميل (Magic Link) |
| `http://localhost:5173` | تجربة محلية (كود demo: **123456**) |

## الإعداد التقني

### 1. السيرفر (Backend)

```bash
# .env في جذر المشروع
MAX_ADMIN_KEY=your-secret-key-here
NEXT_PUBLIC_MAX_PLAYER_URL=https://player.yourdomain.com
```

```bash
npm run dev   # port 3000
```

### 2. المشغّل (Player)

```bash
# stream-hub/.env
VITE_IPTV_API=https://your-domain.com/api/max/iptv
```

```bash
cd stream-hub && npm run dev   # port 5173
```

### 3. APK للعملاء

```bash
cd stream-hub && npm run build:android
```

## الاشتراكات — كيف تعمل

| المفهوم | التفاصيل |
|---------|----------|
| **كود التفعيل** | 4–6 أرقام — هو «اشتراك» العميل |
| **M3U** | قائمة القنوات من مزودك — MAX يعرضها فقط |
| **expiresAt** | تاريخ انتهاء — يُوقف تلقائياً |
| **Magic Link** | `/?code=XXXXXX` — تفعيل بدون كتابة |

---

## Netflix / شاهد / TOD

MAX **يربط** التطبيقات الرسمية — لا يشغّلها داخله.

- العميل يضغط **Apps** في الشريط الجانبي
- يفتح Netflix/شاهد/TOD في تطبيقها الرسمي
- **العميل** يدفع Netflix مباشرة — ليس أنت

---

## الأسئلة الشائعة

**هل يمكن تشغيل Netflix داخل MAX؟**  
لا — DRM قانوني. MAX launcher فقط.

**هل أحتاج TeamViewer لكل عميل؟**  
لا — Magic Link يكفي. افتح الرابط = جاهز.

**ماذا لو انتهى الاشتراك؟**  
العميل يرى «انتهى اشتراكك» — أنت تجدّد من `/max-admin`.

**هل يمكن بيع APK على Google Play؟**  
نعم — كـ «مشغّل IPTV» مع كود تفعيل منك.
